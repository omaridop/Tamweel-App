## 🛠️ Tech Stack
- **Frontend:** React.js
- **Backend:** Python (FastAPI)
- **AI Engine:** Claude API (Anthropic) & RAG Architecture
- **Infrastructure:** Supabase (PostgreSQL)

## ⚙️ How to Run
1. **Backend:** Navigate to `Tamweel_MVP`, run `pip install -r ../requirements.txt` then `python main.py`.
2. **Frontend:** Navigate to `tamweel-ui`, run `npm install` then `npm start`.
